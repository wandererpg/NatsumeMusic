# 右侧曲目表头液态玻璃改造规格

## 目标

将右侧曲目列表的表头（曲目、格式、时长、大小以及操作列）改为轻量、连续的液态玻璃表面，并移除指定的说明性文字；曲目行、单一主滚动容器、播放和打开文件夹功能保持不变。

## 视觉方案

采用“连续玻璃表头带”方案：

- 只改变 `.track-table th`，不恢复外层曲目卡片，也不创建新的滚动容器。
- 使用现有主题变量作为底色和边框来源，使深色、浅色、彩色主题都能保持对比度。
- 使用半透明混合底色、`backdrop-filter: blur()`、轻微饱和度增强、顶部高光和底部阴影，表现玻璃的厚度与悬浮感。
- 第一列和最后一列保留圆角，形成完整的一条玻璃带，而不是每个单元格独立成块。
- 增加 `@supports` 回退：浏览器不支持背景模糊时仍有半透明不透明度足够的表头背景。
- 保留 sticky 表头和现有列宽；行内容不加玻璃背景，确保列表密度和扫描性。

## 已确认的最终风格：边缘折射玻璃

用户从视觉对照稿中选择“边缘折射玻璃”，因此最终实现进一步加入四层材质信号：

- 低不透明度的主题色填充，让背景和主题光晕能透入表头。
- 顶部白色镜面高光与底部内阴影，制造有厚度的玻璃边缘。
- 青、紫、粉三段式外缘光晕，让表头在深色背景上仍能一眼看出玻璃轮廓。
- 在 Chromium 中通过共享的 `natsume-liquid-refraction` SVG 位移滤镜增强边缘折射；不支持该滤镜时自动回退为高饱和度、高亮度的 `backdrop-filter` 模糊玻璃。

同时提供 `prefers-reduced-transparency: reduce` 回退：关闭透明和外缘光晕，改用不透明主题面板，保证可读性和可访问性。

## 追加确认：无彩色玻璃与全局主要文字颜色

用户确认将最终材质收敛为无彩色玻璃：曲目表头不再使用青、紫、粉的渐变填充或边缘光，只保留中性透明层、白色细边、顶部高光、内阴影和折射模糊。SVG 位移滤镜继续保留，但不改变玻璃的色相。

外观设置新增一个全局主要文字颜色选择器和“恢复主题颜色”按钮。颜色作为独立的 `fontColor` 设置保存，默认值为 `null`，表示沿用当前主题的 `--paper-0`；用户选择颜色后通过根元素样式覆盖 `--paper-0`，从而统一影响标题、曲目名、导航、按钮等主要文字，而辅助文字仍使用主题的 `--muted-0`/`--muted-1` 层级色。主题切换、背景预览、取消预览和重启都必须保留该设置语义。

## 文案范围

移除以下可见文本：

- 侧栏底部“仅保存在本机”。
- 曲目标题下“· 双击即可播放”，曲目数量保留。
- 常规曲目列表右侧“按曲目编号”；最近添加列表的“按添加时间”也一并移除，因为当前没有对应的交互排序控件，避免留下无操作的装饰标签。
- 设置中“导入文件会复制到这里，原始游戏目录不会被修改。”。
- 外观设置标题旁“即时预览”。

上述文字所在的布局节点一并清理；文件夹按钮、主题单选、音乐库路径输入、双击播放等功能不改变。图标按钮继续保留 `aria-label` 和 `title`，保证无可见文案时仍可使用和理解。

## 验收标准

1. 右侧曲目表头仍显示“曲目”“格式”“时长”“大小”，并呈现连续的半透明、模糊、高光玻璃表面。
2. 表格仍位于右侧唯一的 `.main-content` 滚动区域内，`.track-table-wrap` 不重新成为嵌套滚动卡片。
3. 指定五类辅助文字在渲染后的可见 DOM 中不存在；曲目数量和实际功能仍存在。
4. 表头在主题切换、悬停、滚动和无 `backdrop-filter` 支持时仍可读。
5. 相关 React 文案测试、CSS 布局/材质测试、TypeScript 检查通过。
