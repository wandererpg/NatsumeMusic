# GalMusic 沉浸式主题卡片设计

## 目标

将设置页中的主题选择卡从“缩略图 + 编号 + 名称 + 说明 + 配色圆点”改为整卡沉浸式预览。用户无需阅读说明，即可从卡片本身辨认主题气质，主题选择区域也会更醒目。

## 范围

- 删除主题名称前的字母编号和分隔点。
- 删除主题说明小字。
- 删除右侧配色圆点。
- 每张卡片只显示主题名称。
- 让卡片的完整背景、纹理、边框、圆角和文字样式呈现对应主题。
- 保持主题即时预览、键盘选择、单选语义、保存和取消行为不变。
- 不修改主题数量、主题 ID、全局背景设置或设置持久化结构。

## 视觉设计

主题网格继续采用双列布局，但卡片高度提升到约 88px。名称作为唯一可见文字，置于卡片主要视觉焦点，并通过局部遮罩或文字阴影确保在明暗背景上清晰可读。

七张卡分别使用独立的材质语言：

- 雨夜青岚：深青雨雾、柔和青绿光晕、细雨纹理。
- 霓虹终端：深紫黑底、青色网格与洋红辉光、硬朗小圆角。
- 琥珀胶片：棕褐渐变、暖色漏光、胶片颗粒与边框。
- 海月玻璃：浅水蓝通透渐变、气泡光斑、大圆角玻璃感。
- 唱片番台：奶油纸底、红蓝几何切片、近直角唱片封套感。
- 绯幕金声：暗红幕布渐变、顶部金色舞台光、金线边缘。
- 音乐手帐：粉彩纸张、横线与贴纸色块、虚线手作边框和轻微旋转感。

卡片不再包含独立缩略图；视觉全部绘制在卡片本体及其伪元素上，避免重复信息。样式由卡片上的 `data-card-theme` 属性选择，不能依赖当前全局主题，确保七张卡始终同时展示各自风格。

## 交互与状态

- 悬停：轻微上浮并增强主题自身的边缘亮度。
- 选中：使用双层高亮描边、轻微放大或抬升，以及右上角勾选标记；高亮颜色来自该卡片自身主题。
- 键盘焦点：保留清晰的 `focus-visible` 轮廓。
- 减少动态效果：遵循 `prefers-reduced-motion`，取消位移和过渡。
- 点击卡片任意位置仍会切换主题并触发即时预览。

## 组件与数据

`SettingsPanel` 继续遍历现有 `THEMES`。每个 `label` 保留隐藏的原生 radio，并将主题 ID 写入 `data-card-theme`。可见内容只渲染主题名称和选中勾选标记。

主题注册表中的 `code`、`description` 和 `swatches` 已不再服务界面。为避免保留无用途数据，将从 `ThemeDefinition` 和主题常量中删除；主题名称与明暗类型继续保留。radio 的无障碍名称只使用主题名称。

## 测试与验收

- 组件测试确认每个主题卡只呈现一个可见主题名称。
- 组件测试确认字母编号、说明文本和配色圆点不再渲染。
- 组件测试确认主题 radio 仍可被名称定位并触发即时预览。
- CSS 合约测试确认每个主题 ID 都有独立的整卡选择器。
- CSS 合约测试确认选中态、焦点态和减少动态效果仍存在。
- 运行完整测试、TypeScript 检查、资源校验和生产构建。
- 重新生成 Windows 成品包并验证 `app.asar` 包含新的主题卡片代码；桌面快捷方式继续指向新包。

## 非目标

- 不新增或删除主题。
- 不改变主界面中七种主题的样式。
- 不改变自定义背景图片及模糊度等全局设置。
- 不加入主题预览动画、声音或外部图片资源。
