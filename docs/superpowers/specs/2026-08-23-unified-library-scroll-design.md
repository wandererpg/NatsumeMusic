# GalMusic 右侧音乐库面板合并设计

## 目标

将单个音乐库中的“全部音乐/最近添加/收藏/播放列表”内容融入右侧主内容外面板，去掉曲目列表内部额外的卡片边界和独立滚动条。用户只需要操作右侧外层滚动区域，就能从库标题、分类筛选一路浏览到音乐菜单。

## 当前问题

当前右侧主内容由 `.main-content` 承担页面滚动，而曲目表 `.track-table-wrap` 又设置了固定最大高度和 `overflow-y: auto`。这会形成两个纵向滚动层：外层页面滚动和内层曲目表滚动。视觉上曲目表也有独立边框、圆角、背景和阴影，像“面板套面板”，不符合用户对单个音乐库的直觉。

## 已确认的设计

### 视觉结构

- 保留右侧主内容区域作为唯一的外层内容面板。
- `track-section` 内的标题、曲目数量、分类筛选、批量操作栏和曲目表保持原有顺序，作为同一条内容流呈现。
- 移除 `.track-table-wrap` 的独立边框、圆角、背景色、阴影、最大高度和纵向滚动样式。
- 曲目表横向仍保持稳定布局；右侧只出现主内容区域的一条纵向滚动轨道。
- 表头继续使用 sticky 定位，使用户下拉浏览长列表时仍能识别列含义。

### 滚动与虚拟化

`.main-content` 是外层滚动容器。`TrackTable` 增加可选的外部滚动容器引用：

```text
App.main-content ref
        │
        ▼
TrackTable.scrollContainerRef
        │
        ├─ 监听外层 scroll 事件
        ├─ 根据外层 scrollTop 与表格在外层中的起始位置换算局部偏移
        └─ 根据外层可视高度计算虚拟曲目窗口
```

当 `TrackTable` 单独使用且没有传入外部容器时，保留现有 `.track-table-wrap` 自滚动作为兼容回退，避免破坏组件预览和已有测试。App 正式页面始终传入 `.main-content` 引用。

切换游戏、分类或搜索结果时，外层滚动位置回到顶部；列表顺序不变时不强制重置用户当前浏览位置。大曲库继续只渲染可视行及 overscan 行，不退化为一次性渲染全部曲目。

## 组件与文件边界

- `src/renderer/src/App.tsx`
  - 为 `.main-content` 建立 ref。
  - 将 ref 传给右侧 `TrackTable`。
  - 保留现有标题、筛选、批量操作和空状态逻辑。
- `src/renderer/src/components/library/TrackTable.tsx`
  - 增加 `scrollContainerRef` 属性。
  - 将滚动监听、视口高度计算和列表重置逻辑抽象为“外部滚动优先、内部滚动回退”。
  - 不改变曲目行操作、选择、双击播放和虚拟窗口算法。
- `src/renderer/src/styles/globals.css`
  - 将 `.track-table-wrap` 改为无卡片边界的内容容器。
  - 保留 `.main-content` 的滚动、滚动条和主题背景承载职责。
  - 在移动端继续保持单一纵向滚动区域。
- `tests/renderer/track-table-virtualization.test.tsx`
  - 增加外部滚动容器测试，确认滚动外层后虚拟列表会显示对应末端曲目。
- `tests/renderer/components.test.tsx`
  - 增加 App 组合测试，确认主内容容器承载曲目表，而不是再创建独立的页面滚动入口。

## 交互与可访问性

- 鼠标滚轮、触摸板、触摸拖动和右侧滚动条都作用于 `.main-content`。
- 表格行、分类按钮、批量操作和操作图标的键盘行为不变。
- 表头 sticky 不遮挡标题或筛选控件；焦点状态、播放状态和选中状态仍使用现有主题 token。
- 不把非交互容器伪装成按钮或拖拽控件；这里的“拖动外面板”指滚动外层内容，不改变无边框窗口标题栏的拖动区域。

## 错误处理与兼容性

- 外部滚动 ref 尚未挂载时，TrackTable 使用内部容器或默认视口高度，不阻塞首次渲染。
- `ResizeObserver` 不可用时，保留现有 fallback 高度和 scroll 事件逻辑。
- 仅改变布局和滚动归属，不触碰主进程、IPC、数据库、播放协议或文件导入逻辑。

## 测试与验收

- 先让外部滚动测试在未实现时失败，再实现最小滚动目标改造并验证通过。
- 运行现有 renderer 组件、播放栏和虚拟化测试，确认既有行为不回归。
- 运行 `npm test`、`npx tsc --noEmit` 和 `npm run build`。
- 人工验收：打开一个有多首曲目的游戏，确认右侧只出现一条纵向滚动条；下拉时“全部音乐”标题、分类和曲目连续移动；曲目表不再出现独立卡片边界或第二条滚动条。

## 非目标

- 不改变左侧游戏/播放列表导航。
- 不改变播放器底栏、播放模式、音量或曲目操作。
- 不删除分类筛选和批量操作，仅把它们放在同一条右侧内容流中。
- 不修改数据库、文件系统或窗口拖拽协议。
