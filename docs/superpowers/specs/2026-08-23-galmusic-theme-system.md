# GalMusic 多主题与全局背景设计说明

## 目标

在不改变现有音乐库布局与操作位置的前提下，为 GalMusic 增加运行时主题切换。现有 A「雨夜青岚」作为默认主题保留；不实现 B「月白樱纸」；新增 C、D、E、F、G、H 六套主题。用户可以导入一张全局背景图，并独立调整模糊度、遮罩强度、缩放和焦点位置。这套背景设置跨主题共用。

## 已确认主题

| ID | 名称 | 视觉语言 | 核心色 |
| --- | --- | --- | --- |
| `rain-afterglow` | 雨夜青岚 | 现有深色玻璃、雨后青绿 | 墨绿、薄荷青、樱花粉 |
| `neon-terminal` | 霓虹终端 | 赛博终端、网格、直角界面 | 黑紫、荧光青、洋红 |
| `amber-film` | 琥珀胶片 | 黄昏胶片、旧磁带、柔和颗粒 | 棕黑、琥珀、旧玫瑰 |
| `aquarium-glass` | 海月玻璃 | 水族馆、通透磨砂玻璃、漂浮光斑 | 云白、水蓝、珊瑚粉 |
| `record-shop` | 唱片番台 | 昭和唱片封套、现代主义排版、收藏编号 | 奶油纸、海军蓝、橘红 |
| `velvet-theatre` | 绯幕金声 | 剧院幕布、金色舞台灯、古典装饰 | 酒红、暖金、象牙白 |
| `scrapbook-diary` | 音乐手帐 | 纸张、贴纸、虚线、轻微手作感 | 腮红粉、薄荷绿、纸张灰 |

主题由统一语义令牌驱动，包括底色、面板、文字、弱文字、主强调色、第二强调色、边线、阴影、圆角和字体。少量 `data-theme` 规则负责主题独有的网格、颗粒、直角、幕布或手帐细节。功能组件不为主题复制。

## 设置模型

`AppSettings` 新增：

```ts
export type ThemeId =
  | 'rain-afterglow'
  | 'neon-terminal'
  | 'amber-film'
  | 'aquarium-glass'
  | 'record-shop'
  | 'velvet-theatre'
  | 'scrapbook-diary';

export interface BackgroundSettings {
  imagePath: string | null;
  blur: number;       // 0..40 px
  dim: number;        // 0..0.85
  scale: number;      // 100..180 percent
  positionX: number;  // 0..100 percent
  positionY: number;  // 0..100 percent
}
```

主题与背景字段继续存入现有 SQLite `settings` 表，不增加新表。读取时对非法或旧值使用默认值；保存时复用现有 `app:set-setting` 通道。

## 界面与交互

设置面板增加“外观”区域：

- 七张主题缩略卡，单击即可在当前应用中即时预览。
- “导入背景图片”调用现有图片文件选择器；“移除背景”恢复主题自带背景。
- 模糊度、遮罩、缩放、水平焦点和垂直焦点使用滑块，并显示当前数值。
- “保存设置”一次性持久化音乐设置和外观设置；取消或关闭时恢复打开设置前的外观。
- 主题切换不改变背景图片和背景参数，背景参数切换主题后仍然保留。

应用根节点通过 `data-theme` 应用主题，并用 CSS 自定义属性传递背景图 URL 和五个背景参数。背景图位于所有界面内容下方；独立模糊层避免对文字和控件应用滤镜。

## 本地图片安全

用户背景可能位于音乐库之外，因此不能复用只允许音乐库内部路径的 `galmusic-cover` 协议。新增 `galmusic-background` 协议：

- 只接受绝对路径与 PNG/JPG/JPEG/WEBP/GIF 文件。
- 请求路径必须与当前持久化的 `background_image_path` 完全一致。
- 不暴露原始文件系统 API 给渲染进程。
- 清除背景后旧 URL 立即失效。

## 容错与兼容

- 老数据库没有外观设置时使用 A 主题和默认背景参数。
- 未安装特定字体时使用各主题定义的中文系统字体回退。
- 图片丢失或协议拒绝时，主题自带渐变仍正常显示。
- 渲染器测试环境没有 Electron bridge 时仍能显示默认主题。
- 遵循 `prefers-reduced-motion`，主题切换不依赖动画完成状态。

## 验收标准

1. 设置面板中可选择 A、C、D、E、F、G、H，不出现 B。
2. 切换任一主题后全局组件立即使用对应视觉令牌。
3. 导入背景图后可调整模糊、遮罩、缩放和焦点位置。
4. 从一个主题切到另一个主题，背景路径与参数不重置。
5. 重启应用后主题和背景设置恢复。
6. 非法主题、越界数值和未授权图片路径均安全回退或拒绝。
7. 现有测试、TypeScript 检查、资源检查和生产构建全部通过。
