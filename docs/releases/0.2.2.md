# NatsumeMusic 0.2.2

构建日期：2026-10-21 · Windows x64

## 相比上次打包的 0.2.1

### 新增

- 与 NatsumeNote 手动双向同步：在设置中导出完整同步文件夹，在另一端选择 `manifest.json`，预览差异并确认合并歌曲、收藏、播放列表、作品资料和封面。重复导入会查重，保留本地作品 ID 与名称；手账、设置和删除操作不参与同步。NatsumeNote 也需要使用包含同步功能的新版源码或后续安装包，原 0.1.0 EXE 不支持此接口。
- 支持 Alicesoft `.afa` 音频资源包，处理 AFA 1/2 文件表与中文、日文文件名，按选项跳过语音包，改善《多娜多娜 一起干坏事吧》等游戏的音乐导入。
- 支持 BGI/Ethornell 无扩展名 `BURIKO ARC20` / `PackFile` 资源，识别 BW/OGG 音频并跳过图片和脚本，改善《素晴日》等游戏的音乐导入。

### 改善

- 调整作品封面、音乐库信息层级、文字对比度与小窗口布局，保留已有转场、按钮动效和加载提示。
- 完善键盘操作、设置弹窗焦点循环与关闭后的焦点恢复；没有曲目时禁用播放器空操作。

### 修复

- 同一首曲目前的播放键再次点击会暂停，之后继续播放，不再每次从头开始。
- 删除曲目后保留列表滚动位置，避免跳回页面开头。
- 重新搜索或确认同一作品资料时保留已有补充信息，避免覆盖中文简介与扩展资料。
- 同步后的转换音频保留原始来源标识，防止再次导入原 NWA/OWP 资源时重复收录。

0.2.1 已有的设置保存修复、已有歌曲目录识别、VNDB/Bangumi 候选确认、页面加载转圈及应用内更新功能继续包含在本安装包中；这些不重复计为本次新增。

## 安装与使用

- 安装版：关闭正在运行的旧版，运行 `NatsumeMusic-0.2.2-x64.exe`，选择原安装目录。音乐库和应用数据继续保留；重要数据建议事先备份。
- 安装版压缩包：解压 `NatsumeMusic-0.2.2-windows-x64-installer.zip` 后运行其中的 EXE。
- 便携版：完整解压 `NatsumeMusic-0.2.2-windows-x64-portable.zip`，运行 `NatsumeMusic.exe`，保留旁边所有文件与 `resources` 目录。
- 同步操作说明：[双向同步操作说明](../library-sync-guide.md)。
