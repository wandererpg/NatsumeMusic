# NatsumeMusic 0.2.1

适用平台：Windows x64。

## 本次更新

- 调整音乐库外观，增加作品封面浏览、页面转场、按钮按压和选中反馈。
- 页面导航立即读取曲目，较慢的读取显示轻量转圈提示；快速切换以最后一次选择为准，遵循系统减少动态效果设置。
- 修复外观保存等待；普通设置保存不再重新扫描音乐库，新增明确的「重新扫描歌曲」操作。
- 改善音乐目录切换，选择已有歌曲的目录后扫描并更新音乐库。
- 改善 VNDB、Bangumi 关联资料的搜索、候选预览、确认与重新选择，修复错误信息显示及旧数据库迁移问题。
- 增加安装版应用内检查更新、下载及备份后安装流程。0.1.0 客户端需要先手动安装支持更新的新版本。

## 下载与安装

- 安装版：运行 `NatsumeMusic-0.2.1-x64.exe`，建议关闭旧版后选择原安装目录。
- 便携版：完整解压 `NatsumeMusic-0.2.1-windows-x64-portable.zip`，运行目录内的 `NatsumeMusic.exe`；保留全部文件和 `resources` 目录。
- `SHA256SUMS.txt` 提供下载文件的 SHA-256 校验值。
